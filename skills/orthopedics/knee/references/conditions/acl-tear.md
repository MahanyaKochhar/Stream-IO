# ACL Tear

Use with the shared checklist in `SKILL.md`.

Use these additional findings for documented or suspected ACL injury. Imaging
findings, including associated injuries, belong to `imaging.knee_summary`. Do not infer an ACL tear from symptoms or apply this
reference to an isolated PCL injury.

## Requirement definitions

```yaml
requirements:
- id: acl.injury_context
  description: Acute injury features
  guidance: Activity at injury, audible pop, and timing of acute swelling.
- id: acl.ligament_exam
  description: ACL examination
  guidance: Lachman, anterior drawer, or pivot-shift findings.
```
